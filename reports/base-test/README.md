# 未微调模型的测试集基线

本次评测使用 qwen3-dataset-v1 中冻结的 100 条 test 样本。它们没有参与之前的参数训练或最佳训练轮次选择。这里只运行原始 Qwen3-1.7B，不加载已训练的 LoRA，也不继续训练。

使用 ../qwen3-validation-baseline/evaluate_validation.py 的 --split test 选项。该选项仅改变读取的数据集及报告标识，复用原评分代码。模型输入只有任务规则和评论，参考答案在输出生成后用于评分。

与之前验证集基线相同：NF4 双重量化、BF16 计算、SDPA、关闭思考、贪心生成、批量 4、最多生成 512 token。模型权重、提示词、评分代码与推理设置均已核对。protocol.json 保存测试数据哈希和实际设置。

base-nf4-test-100 目录包含：

- predictions.jsonl：100 条模型原始回答、标准答案及逐项评分。
- metrics.json：汇总成绩。
- report.md：中文报告与未全部通过的题目。
- protocol.json：模型与推理设置。

整条标签正确要求方面、情感与复购标签均匹配，不要求引用依据与参考答案完全相同。依据检查只验证是否为原文连续片段，不自动证明支持对应结论。格式合规率检查规定字段和标签，不代表内容正确。

测试数据仍是同一生成流程制作的合成评论，成绩不能代表真实评论总体表现。应保持已经选好的 LoRA 和推理方案不变，随后再进行微调后的配对测试；不能通过反复查看测试错误来调整当前实验模型。
